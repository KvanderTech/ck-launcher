# SPEmotes preview animations

This directory contains a small, curated subset of SPEmotes animations used by the skin preview:

- `yes.json`
- `bow.json`
- `extend-arms.json`
- `wave.json` (native preview; elbow and torso bends)

Animation author: SPEmotes / Milyan. Source: https://spemotes.com/download/

The files are used only for cosmetic preview animation inside CK Launcher. They do not modify Minecraft or transmit emotes to a game server.
