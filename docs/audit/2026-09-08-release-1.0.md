# Проверка исправлений 1.0.0

Проверка выполнена на отдельной ветке от 0.2.4-beta.1, без запуска установщика поверх пользовательской копии и без доступа к токенам аккаунтов.

## Причины и исправления

| Проблема | Причина | Исправление |
| --- | --- | --- |
| Скины исчезали после выхода | `ON DELETE CASCADE` связывал библиотеку с удаляемой записью входа | Схема 5 с постоянным UUID-владельцем, резервная копия базы, транзакционный перенос PNG |
| Выделения у названий | Кастомная анимация кнопки рисовала фон поверх текстовой кнопки | Текстовые кнопки исключены из рисования фона, клики и клавиатура сохранены |
| Всплывающие панели при наведении | Стандартные `ToolTip` | Подавление только события подсказки; доступные имена и рабочие меню не удалены |
| Пустые/сломанные описания | Смешанный HTML/Markdown, фиксированная геометрия картинок, запрещённые ранее публичные хосты | CommonMark + HTML5-очистка, адаптивные картинки, ограниченный HTTPS-список источников |
| Значки установленных модов | Импорт `.mrpack` сохранял имя файла, не подтягивая карточку проекта | Пакетный запрос метаданных по ID, кэш и сохранение состояния файлов; увеличена ограниченная очередь иконок |
| Непонятная загрузка | Общий статус без событий контента/Java/обновления | Этапы, измеренные байты/файлы, проценты, отмена; неизмеримые этапы не получают фиктивных процентов |
| Крупные плащи | Растягиваемые карточки с отдельной миниатюрой и подписью | Плитки 72×116, фактура плаща на всю плитку, тонкий акцент выбора |

## Проверено локально

- Rust workspace: 241 успешный тест; сетевой тест настоящего Forge остаётся отдельным opt-in.
- Qt 6.8.3 и Qt 5.15.2: наборы protocol, interface, project-versions, emotes.
- Скины: вход/выход/повторный запуск, другой ID и имя входа при том же UUID, UUID с дефисами/заглавными буквами, разделение двух аккаунтов, избранное/название/активный выбор, перенос старой папки, восстановление осиротевших PNG, откат файлов при отказе SQLite, обновление схемы 4 → 5 с резервной копией.
- Modrinth: реальная публичная страница Cobblemon `5FFgwNNP` (93 пункта списка); все 7 уникальных картинок получены через сервис, включая изображения больше прежнего лимита 2 МБ. Очищенная страница просмотрена в Qt, проверена при изменении ширины.
- В тестовой базе установленный `sodium.jar` получил настоящее название Sodium и иконку; имя файла и отключённое состояние сохранились.
- Прогресс: измеренный объём локального HTTP-ответа, отмена, 50% в UI, переход в этап без известного размера, очистка после ошибки и повтор установки.
- Обновления: принят переход обеих native-бет на 1.0.0, запрет смены канала и отката; стабильная версия не принимает будущую beta.
- Навыком computer-use проверены реальное окно изолированного предпросмотра, новый рендер, разворачивание и компактные плащи. Основная библиотека пользователя не изменялась.
- Первый CI обнаружил отличие Windows-путей: короткий alias профиля (`RUNNER~1`) не совпадал с полным сохранённым путём скина. Ошибка воспроизведена отдельным тестом, исправлена нормализацией директорий с сохранением проверки reparse points и запрета выхода за папку скинов.

## Выпуск и ограничения

Публикация выполняется только после зелёной сборки точного Git-тега для Modern, Legacy и переходного web-адаптера. ZIP обоих каналов подписываются существующим native-ключом; проверяются состав пакета, SHA-256, исходный коммит и подпись. Установщики и ZIP публикуются одним стабильным выпуском.

Фактический вход Microsoft, игра с каждым существующим модпаком и реальная Windows 7/8.1 этим прогоном не покрыты. Доступность внешних сервисов не гарантируется. Это ограниченный воспроизводимый набор регрессионных проверок, а не утверждение об отсутствии любых ошибок.
