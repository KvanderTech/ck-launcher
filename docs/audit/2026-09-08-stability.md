# Проверка стабильности 0.2.4-beta.1

Проверка проведена по всем пользовательским разделам и связанным подсистемам. Это матрица покрытия и найденных регрессий, а не обещание отсутствия любых ошибок.

Использованы отдельный рабочий каталог, временные APPDATA/SQLite/INI и тестовые аккаунты/изображения. Реальные аккаунты, скины, сборки и установка пользователя не изменялись. Эмулятор сервиса не входит в выпуск.

| Область | Проверка и исправления | Граница |
| --- | --- | --- |
| Главная, навигация, библиотека | Снимки обычного/минимального окна, 12 сборок, прокрутка, скругления, клавиатурный фокус, клики по карточкам | Другие темы Windows и все мониторы физически не перебраны |
| Проекты Modrinth | Описание, фильтры, точный ID релиза, целевая сборка, таблица/форма, длинные названия, пустая выдача, ошибки и повтор, блокировка повторной установки | Не установлен каждый проект Modrinth |

## Воспроизводимые проверки

- Rust: `cargo test --workspace --locked`. Локальный полный прогон: 231 passed, 1 opt-in Forge integration ignored.
- Реальный service: `scripts/test-service.py` с временным APPDATA — протокол, Unicode, жизненный цикл сборок, импорт/repair и отклонение небезопасных путей/источников.
- Qt: `ctest --test-dir build/qt -C Release --output-on-failure`: protocol, interface, project-versions, emotes — полный локальный прогон прошёл. Дополнительно protocol/interface/project-versions прошли при 100%, 125% и 150%; последние изменения повторно проверены при 100% и 150%. Снимки сохраняются в `build/qt/ui-screenshots`.
- Изолированная визуальная проверка: `ui-preview` (тестовый target, только `ui-fixture`); не регистрирует протоколы, не обращается к реальным аккаунтам.
- Первый CI обнаружил падение Legacy в project-versions. Найдено обращение к прежнему QTextDocument после его удаления внутри `setDocument`; применён QPointer и добавлена регрессия первого/повторного открытия. Удаление документа подтверждено в [исходнике Qt 5.15.2](https://github.com/qt/qtbase/blob/v5.15.2/src/widgets/widgets/qwidgettextcontrol.cpp#L845-L859). Дополнительно устранён конфликт имени параметра SkinView с макросом `small` из Windows RPC при локальной сборке Qt5/MSVC.
- После исправления project-versions (13 проверок с init/cleanup) прошёл 20 последовательных повторов на Qt 5.15.2/MSVC и ещё 20 на Qt 6.8.3/MSVC. Локальный отказ проверки WebP относился к неполному диагностическому SDK; официальный модуль qtimageformats добавлен. В CI и пользовательских пакетах этот модуль обязателен и проверяется отдельно.
- CI собирает и проверяет Modern/Qt6 и Legacy/Qt5, переходную оболочку, лицензионные файлы, DLL, установщик и изолированный запуск готового пакета.
- Перед публикацией проверяются commit в SOURCE.txt, версии EXE, SHA256 всего пакета и подпись ZIP прежним ключом; неполный или не прошедший CI пакет не публикуется.

Реальные Windows 7/8.1 не проверены; запуск Legacy в CI на Windows Server не заменяет эту проверку. Установщик и updater не подписаны сертификатом Authenticode. Условия совместимости см. в [NATIVE_BUILD](../NATIVE_BUILD.md).
