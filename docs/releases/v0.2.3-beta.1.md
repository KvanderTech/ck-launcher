# ЦК Лаунчер 0.2.3-beta.1

Исправление эмоций в предпросмотре скина и установка сборок Forge.

- Исправлено чтение старого формата SPEmotes: движение всего персонажа больше не применяется только к грудной клетке.
- Исправлены единицы смещения и центр наклона тела. Во время поклона корпус, голова, руки и ноги двигаются согласованно.
- Переработаны сгибы локтей и коленей: поверхности соединяются в суставе, концы конечностей не деформируются. Учтены разные центры обычных и тонких рук и внешние слои скина.
- Исправлены направление оси сгиба, выбор функции плавности и переходы между ориентациями. При возврате в обычную стойку конечности не делают лишний оборот.
- Вращение мышью во время эмоции, избранное, поиск и остальные возможности сохранены.

Добавлены проверки формата Emotecraft, единиц и осей координат, замкнутости суставов, полного цикла анимации и изображений всех четырёх эмоций для классической, тонкой и старой 64×32 модели.

## Сборки Forge

- Исправлена ошибка «неподдерживаемый загрузчик» при установке сборок Forge, в том числе Zombie Invade 100 Days для Minecraft 1.20.1.
- Добавлена подготовка Forge через официальный установщик с проверкой контрольной суммы; существующая папка `.minecraft` и её профили не изменяются.
- Forge можно выбрать при создании сборки, использовать в Modrinth и импортировать из `.mrpack`. Подходящая Java подбирается автоматически.
- Добавлена проверка созданных Forge библиотек и поддержка восстановления через настройки сборки. Ограничения безопасных параметров Java сохранены.

Старый установщик Forge для Minecraft 1.12.2 и ниже и NeoForge пока не поддерживаются. Совместимость конкретных модов со старой Windows не гарантируется. [Подробнее](../FORGE.md).

## Обновление

В нативной бете откройте **Настройки → Проверить обновления**. Пакеты Modern и Legacy подписаны прежним ключом автообновления. Сборки, скины и аккаунты сохраняются.

Для ручной установки на Windows 10/11 используйте `ck-launcher-qt-modern-windows-x64-setup.exe`. Ограничения старых Windows описаны в [инструкции](../NATIVE_BUILD.md).

Подпись автообновления не является сертификатом Microsoft Authenticode; предупреждение SmartScreen всё ещё возможно.
