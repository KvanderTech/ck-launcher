# ЦК Лаунчер 1.0.0

Первый стабильный релиз нативного ЦК Лаунчера — без отметки beta.

## Что изменилось

- Новый рендер на главном экране. Социальные иконки привязаны к расположению заголовка и не съезжают при разворачивании окна.
- Библиотека скинов привязана к Minecraft UUID, а не к записи входа. Файлы хранятся отдельно в `skins/<uuid>/`; выход из аккаунта не удаляет библиотеку, названия и избранное.
- При первом открытии скинов старые файлы безопасно переносятся. Перед обновлением схемы создаётся резервная копия базы. Перенос откатывается, если запись в базу не удалась.
- PNG, оставшиеся после выхода из старой беты, восстанавливаются из прежней папки этого аккаунта. Если старая версия уже удалила названия и избранное из базы, восстановленные PNG получают имя «Восстановленный скин».
- Убраны лишняя подсветка названий и всплывающие подсказки при наведении. Клики по всей карточке, управление с клавиатуры и функциональные меню сохранены.
- Описания Modrinth проходят полноценный разбор смешанной Markdown/HTML-разметки. Исправлены списки, заголовки, спецсимволы и масштабирование изображений. Скрипты, внешние стили, локальные URL и исполняемые вставки не загружаются.
- Установленные моды из `.mrpack` получают названия и иконки Modrinth, в том числе в ранее созданных сборках. При недоступной сети остаются сохранённые метаданные; содержимое и состояние файлов не меняются.
- Индикатор показывает этап, фактические проценты, объём загрузки и количество файлов: Minecraft, контент, архив сборки, Java, Forge и обновление лаунчера. Для этапов без измеримого размера показывается статус, а не фиктивный процент.
- Плащи стали компактными портретными плитками без больших рамок и пустых полей. Выбранный плащ отмечен тонким акцентом; доступен вариант «Без плаща».

## Установка и обновление

Windows 10/11 x64: **Modern**. Windows 7 SP1/8.1 x64: **Legacy**; ограничения игр и загрузчиков на старой ОС описаны в [NATIVE_BUILD.md](../NATIVE_BUILD.md).

В версии 0.2.4-beta.1 откройте **Настройки → Проверить обновления**. Лаунчер выберет ZIP для своего канала и проверит криптографическую подпись перед заменой файлов. Также доступны отдельные установщики. Сборки и аккаунты не требуется удалять или создавать заново.

После перехода на стабильную 1.0.0 предлагаются стабильные обновления; будущие беты автоматически не устанавливаются. Старые версии 0.1.x на Tauri не поддерживают этот нативный путь обновления — используйте установщик.

## Границы проверки

Тесты не являются гарантией отсутствия любых ошибок. Работа внешних Microsoft/Modrinth/CDN, конкретных модов и совместимость новых версий Minecraft со старой Windows зависят не только от лаунчера. Пользовательские пароли и настоящий вход Microsoft при проверке не использовались.
