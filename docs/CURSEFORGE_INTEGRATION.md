# CurseForge в Kvanth Launcher

Каталог обращается к официальному CurseForge Core API из нативной части приложения. Ключ не хранится в репозитории, веб-коде, файлах настроек и журналах. Сборка без ключа показывает понятную ошибку при открытии CurseForge; Modrinth продолжает работать.

Для локальной сборки установщика Windows 11 откройте PowerShell в корне проекта и выполните:

```powershell
.\scripts\build-win11-curseforge.ps1
```

Скрипт запросит ключ скрытым вводом, передаст его только процессу сборки и удалит переменную окружения после завершения. Не вводите ключ в командную строку, `.env`, исходники, issue или переписку. Готовый установщик появится в `app/src-tauri/target/release/bundle/nsis` (либо в каталоге сборки, указанном Cargo).

Ключ, встроенный в приложение, нельзя сделать криптографически секретным от владельца компьютера: его можно извлечь из бинарного файла при целенаправленном анализе. Такой способ лишь не публикует ключ в исходниках и интерфейсе. Если CurseForge требует невозможности извлечения ключа пользователями, нужен собственный сервер-посредник и отдельное согласование условий.

Поиск, версии, моды, ресурспаки, шейдеры и ZIP-сборки используют официальный API. Для загрузки файлов ключ передаётся только проверенным хостам CDN CurseForge: с июля 2026 года этого требует сам CDN. Лаунчер проверяет разрешение на распространение, наличие URL, SHA-1 и размер; не строит альтернативные ссылки на CDN и не обходит запреты авторов. Для несовместимого или недоступного файла установка прерывается с объяснением. Обязательные зависимости отдельных модов устанавливаются перед модом.
