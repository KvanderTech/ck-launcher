# Kvanth Launcher 1.0

Первый выпуск лаунчера под названием Kvanth Launcher для Minecraft: Java Edition.

- Один установщик для Windows 10 и 11 x64. При необходимости он устанавливает Microsoft Edge WebView2 Runtime из встроенного офлайн-пакета.
- Обновлённый интерфейс Kvanth, библиотека сборок, скины и плащи, каталог Modrinth и CurseForge.
- Подписанные обновления прямо из настроек лаунчера. Будущие выпуски должны содержать установщик, его `.sig` и `latest.json`, подписанные тем же ключом.
- Вход Microsoft, запуск Vanilla, Fabric, Quilt и Forge, настройка Java и памяти.

SHA-256 установщика: `B04A321FFC2CA3E744B44113716040BC90E1143737252867831AC340A9892C48`.

Важно: код и интерфейс проверены автоматическими тестами, но перед широким распространением рекомендуется проверить установку и запуск игры на чистых Windows 10 и 11. Закрытый ключ обновлений не публикуется и должен храниться отдельно от репозитория.
