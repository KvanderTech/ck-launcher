# Kvanth Launcher (ранее «ЦК Лаунчер»)

Лаунчер для комфортной игры в Minecraft: Java Edition на Windows.

[Telegram](https://t.me/kvanth_launcher) · [Discord](https://discord.gg/2CkZsVN8nm)

**Kvanth Launcher 1.0** — единый установщик для Windows 10 и 11 x64. Если WebView2 Runtime отсутствует, установщик добавит его из встроенного офлайн-пакета. [Скачать выпуск](https://github.com/KvanderTech/ck-launcher/releases/latest).

**Для установки и использования официального выпуска не нужны собственные ключи CurseForge или Microsoft.** Ключ CurseForge уже включён в официальный установщик при сборке; вход через Microsoft настроен в лаунчере. Достаточно скачать и запустить установщик.

Форки исходного кода допускаются по AGPL-3.0, но не становятся официальными выпусками Kvanth Launcher и должны использовать собственное название и оформление. ## Релиз 1.0

Новый интерфейс Kvanth работает на Tauri 2 / React и общем игровом ядре Rust. В выпуск входят библиотека сборок, каталоги Modrinth и CurseForge, управление скинами и плащами, а также подписанные обновления из настроек лаунчера. [Изменения Kvanth 1.0](release/kvanth-1.0.0/RELEASE_NOTES.md).

Исторические выпуски «ЦК Лаунчера» и документация по прежнему Qt-интерфейсу остаются в истории Git и [архивной документации](docs/NATIVE_BUILD.md), но не являются актуальным установщиком Kvanth.

## Возможности

- вход через Microsoft с проверкой лицензии Minecraft;
- отдельная библиотека версий и сборок;
- поиск модпаков, модов, ресурспаков и шейдеров через Modrinth;
- фильтрация по версии Minecraft, загрузчику и категории;
- просмотр описания проекта и выбор конкретного релиза;
- установка сборок из Modrinth и локальных файлов `.mrpack`;
- поддержка Vanilla, Fabric, Quilt и Forge при создании и запуске сборок (ограничения Forge — в [документации](docs/FORGE.md));
- управление установленным контентом, файлами, мирами и журналами;
- установка подходящей Java и настройка оперативной памяти;
- проверка и установка подписанных обновлений Kvanth прямо из настроек лаунчера;
- управление скинами и плащами лицензионного аккаунта;
- единый индикатор установки, который сохраняется при переходе между вкладками.
- звуки кнопок, выбора сборки и скина, запуска и завершения игры;
- периодические эмоции предпросмотра скина: кивок, приветствие рукой, разведение рук и поклон; вращение мышью сохранено.

## Безопасность

- пароль вводится только на официальной странице Microsoft — лаунчер его не видит и не хранит;
- авторизация использует OAuth 2.0 Authorization Code с PKCE и одноразовый `state`, защищающий локальный callback от подмены;
- refresh-токены хранятся отдельно от SQLite в Windows Credential Manager, защищённом учётной записью Windows;
- Rust-ядро не возвращает токены в Qt или React/WebView и не помещает их в события интерфейса;
- известные секреты и поля `access_token`/`refresh_token` вырезаются из журналов, включая данные, разделённые между порциями вывода процесса;
- интерфейс WebView2 работает с ограничениями CSP; токены не передаются в React;
- пути архивов и библиотек проверяются против выхода за каталог и ссылок; файлы модпаков требуют хеш и размер, архивы проверяются до распаковки;
- локальный модпак сначала проходит предпросмотр с подтверждением, а загрузки имеют ограничения размера и разрешённых HTTPS-источников;
- «Показать в Проводнике» выделяет файл без его запуска, журналы очищаются до вывода и экспорта;
- обновлятор Tauri проверяет подпись установщика открытым ключом Kvanth до установки;

Это снижает риск кражи токена со стороны веб-контента, логов и подменённых обновлений. Как и любое локальное приложение, лаунчер не может защитить данные от вредоносной программы, уже запущенной с правами самого пользователя или администратора Windows.

## Сборка из исходного кода (для разработчиков)

Этот раздел не относится к установке готового официального выпуска. Для самостоятельной сборки нужны Windows 10/11 x64, Node.js, npm и Rust MSVC. Скрипт запрашивает ключ CurseForge Core API, который встраивается в собираемое приложение, и путь к закрытому ключу подписи обновлений. Официальный ключ CurseForge и закрытый ключ подписи KvanderTech в репозитории не публикуются. Авторам форков нужны собственные ключ CurseForge и регистрация приложения Microsoft; для выпуска подписанных автообновлений — собственная пара ключей подписи. Готовый установщик добавляет WebView2 при необходимости.

```powershell
.\scripts\build-win11-curseforge.ps1 -SigningKeyPath <private-key-path>
```

## Подписанные обновления

Лаунчер проверяет `latest.json` в последнем GitHub Release. Для каждого нового выпуска нужны NSIS-установщик, его `.sig` и `latest.json` с той же подписью. Закрытый ключ хранится вне Git; его потеря лишит установленные копии возможности доверять новым обновлениям. [Подробности выпуска](docs/KVANTH_REBRAND.md).

Дополнительные сведения: [`app/docs/privacy-and-logs.md`](app/docs/privacy-and-logs.md) и [`app/docs/windows-acceptance.md`](app/docs/windows-acceptance.md).
